# Website Launch Checklist

## Before launch
- [ ] Finalize GitHub repo and production branch
- [ ] Confirm Netlify site is connected to the correct repo
- [ ] Point domain to the final Netlify deployment via Cloudflare DNS
- [ ] Confirm the site is live on HTTPS
- [ ] Test the phone number and CTA links
- [ ] Test the estimate form submission flow
- [ ] Verify all images load with proper compression
- [ ] Check reviews and text for accuracy
- [ ] Verify local business address and service-area copy matches Google Business Profile
- [ ] Check navigation and mobile responsiveness

## Content validation
- [ ] No placeholder text remains
- [ ] All service pages reflect real offerings
- [ ] Review quotes are real and attributed correctly
- [ ] Job photos are real and legally usable
- [ ] Business name, phone number, and hours are accurate
- [ ] License and insurance claims are validated and clearly written

## SEO and technical validation
- [ ] Schema markup present
- [ ] Robots.txt and sitemap configured
- [ ] Core Web Vitals acceptable
- [ ] Security headers enabled
- [ ] Forms are spam protected and monitored
- [ ] Search Console and analytics connected

## Post-launch optimization
- [ ] Monitor lead volume by source
- [ ] Review mobile conversion behavior
- [ ] Improve copy based on user behavior
- [ ] Refresh photos and reviews as more work is completed
- [ ] Add service-area expansion pages as needed

## Recommended launch standard
- Design should feel premium, local, and clear
- Performance should feel fast on mobile
- Trust should be visible without feeling cluttered
- The site should always prioritize cost-to-lead and quote conversion over decoration
