# Website Phase Roadmap

## Phase 1 — Foundation and architecture
- Create a clean GitHub repo for the active production website
- Establish a simple, secure static site structure
- Set up Netlify deployment pipeline
- Configure DNS through Cloudflare to point the actual domain cleanly
- Standardize brand tokens, typography, spacing, and CTA patterns
- Build a clean shared CSS system and reusable components

## Phase 2 — Home page and conversion core
- Launch a polished homepage with strong hero CTA
- Include phone-first conversion and simple estimate form
- Add review highlights and portfolio section using real Google reviews/photos
- Show service categories and trust badges
- Include clear customer value proposition and local relevance

## Phase 3 — Service and location pages
- Interior painting page
- Exterior painting page
- Cabinet refinishing page
- Deck and fence staining page
- Service area pages for Vancouver, Camas, Battle Ground, Washougal, Ridgefield
- FAQ and process pages for search intent and conversion confidence

## Phase 4 — Trust and SEO layer
- Local business schema markup
- NAP consistency across the site
- Google Business Profile integration with review summary
- Subpages targeting service-area and neighborhood intent
- FAQ schema and structured content blocks

## Phase 5 — Security and performance hardening
- Security headers
- CSP and anti-clickjacking settings
- Image optimization and responsive asset delivery
- Core Web Vitals targeting
- Spam-resistant form setup and validation

## Phase 6 — Launch and optimization
- Deploy to Netlify
- Confirm domain and SSL behavior
- Run final QA on desktop/mobile
- Review form submissions and phone tracking
- Monitor Google Search Console and conversion behavior
- Iterate by service and geography based on actual inbound conversion data

## Recommended delivery sequence
1. Homepage
2. Services pages
3. Service-area pages
4. Reviews and gallery improvements
5. FAQ and trust pages
6. Security and optimization pass
7. Launch and analytics

## Success metrics
- Fast mobile load speed
- Strong conversion from phone CTA and estimate form
- Improved local discovery in Clark County
- Higher average quote conversion rate
- Better visibility for premium residential painting services
